三种实现路径

方案 A：渐进增强（推荐）

做法

  • 保留现有 Vico 图表
  • 新增概览行 + Tab 布局 + 时间筛选器
  • 指标卡片增加环比箭头 + 迷你 sparkline
  • 新增环形图 api 显示训练类型分布
  • 依赖：新增少量 DAO 查询（周环比、力量历史）

优点

  • 改动可控，Vico 已集成
  • 数据源完整，工作量适中
  • 容易测试和增量上线

方案 B：图表库替换

做法

  • 替换 Vico 为 MPAndroidChart 或 YCharts
  • 获得更丰富的图表类型和交互
  • 同上布局改造

缺点

  • 额外依赖，View interop 增加复杂度
  • Vico 已经满足基础需求，替换收益不大
  • 迁移成本高

方案 C：自定义 Canvas 绘制

做法

  • 用 Compose Canvas 手绘所有图表
  • 完全控制样式和交互
  • 无第三方依赖

缺点

  • 开发量大（折线图、柱状图、环形图、sparkline）
  • 触摸交互/动画/无障碍需要手写
  • 可维护性更低

推荐方案 A — Vico 已集成且能覆盖需求，重心应放在布局和信息设计上，而不是替换图表库。
