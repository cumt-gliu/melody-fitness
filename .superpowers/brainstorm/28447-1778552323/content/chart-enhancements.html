方向 3：图表视觉增强

三处增强，让图表信息更丰富

① 有氧趋势面积渐变填充

当前为纯折线，增加从主色到透明的渐变填充，视觉上更饱满。

实现：Vico rememberLineCartesianLayer(areaFill = ...) 或 Canvas 手绘

② 力量重量 PR 标记点

当前只在底部文字标注 PR 值，改为在图表折线上标记橙色圆点 + 标签。

实现：Canvas 叠加绘制标记点，非 Vico 原生

③ Tooltip 数据点提示

触摸/点击折线图数据点，弹出日期 + 数值提示框。以下图表受益：

  • 有氧时长趋势 → "5/10 · 35 分钟"
  • 体重+体脂叠加图 → "5/10 · 72.3 kg · 15%"
  • 力量重量趋势 → "5/10 · 60 kg"

实现：Vico 内置 rememberCartesianChart(marker = rememberMarker())
