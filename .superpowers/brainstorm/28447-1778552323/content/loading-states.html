加载状态检测

StatsUiState 新增字段：

data class StatsUiState(
    // ... 现有字段
    val isOverviewReady: Boolean = false,  // 概览数据是否已加载
    val isTabDataReady: Boolean = false,   // Tab 数据是否已加载
)

首次加载时显示骨架屏，后续数据刷新时数据内容原地过渡。
