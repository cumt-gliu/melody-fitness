方向 5：粘性头部 + 滚动行为

当前所有内容整页滚动，概览行和筛选器会滚出屏幕

当前布局（问题）

滑动后概览行和筛选器移出屏幕

改进方案

将布局拆分为上下两层：

固定头部
概览行（4 卡片）
时间筛选器
Tab 导航
▼ 可滚动区域
Tab 内容区（独立滚动）
建议卡片

实现方式

不需要 LazyColumn。用两层嵌套布局：

Column {
    // 固定头部（不滚动）
    Column(modifier = Modifier.fillMaxWidth()) {
        OverviewRow(...)
        TimeRangeFilter(...)
        StatsTabRow(...)
    }
    // 可滚动内容
    Column(
        modifier = Modifier
            .weight(1f)
            .verticalScroll(rememberScrollState())
    ) {
        TabContent(...)
        StatsAdviceCard(...)
    }
}

说明：固定头部始终可见，下方内容区独立滚动。需要配合父级 Scaffold 的 paddingValues 调整。
